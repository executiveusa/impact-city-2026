# Impact City — Cinematic Shot List

Shot-by-shot plan for the Unreal intro cinematic. Matches the web hero's
narrative beats so the two reinforce each other. Total target: ~60s.

## Scene 01 — The Great Override (~12s)

| Shot | Frame | Description |
|---|---|---|
| 1.1 | 0–3s | Wide aerial of Rustgarden at dusk, emerald cracks glowing |
| 1.2 | 3–6s | Push-in on watchtower, blue light sweeping |
| 1.3 | 6–9s | Montage: gate closing, screens flickering, vines growing |
| 1.4 | 9–12s | Tilt up to broken skyline, narration beats |

## Notes

- Procedural proxies are acceptable for blocking; swap to production meshes before final render.
- All shots use the Emerald Gothic Hopepunk palette (obsidian, rust, moss, emerald, amber).
- No violence, no weapons — per canon.
- Reduced-motion: provide a static keyframe per scene as an accessibility fallback.
