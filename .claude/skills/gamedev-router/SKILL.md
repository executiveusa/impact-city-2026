# gamedev-router

Read `game-dev-skills/README.md` at the repo root first. It fingerprints this repo's
engine per branch (web/React on `main`, three.js via react-three-fiber on `feat/3d-*`),
names the minimal skill set for common tasks, and lists this repo's hard rules
(nonviolent, kid-safe, skills are guidance not authority, no new frameworks).

Then follow `game-dev-skills/router/SKILL.md` to resolve the exact skills, read only
those `SKILL.md` files under `game-dev-skills/skills/`, and act.
